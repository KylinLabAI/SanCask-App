# SanCask (安匣)

[中文](README.zh.md)

![SanCask Logo](resources/logo_256.png)

A medical record organizer that photographs records, reports and medicines, files them locally, and shows indicator trends.

## Features

- **Photo capture with on-device OCR and local structured field extraction**
- **Medical records lifecycle: outpatient/inpatient records, cross-hospital disease trends and report export**
- **Imaging-report fields with image crop-and-preview**
- **Health checkup management: annual indicator trends, nodule/cyst tracking**
- **Medicine ledger: photo/manual entry, grouping by condition, expiry reminders, per-member isolation**
- **Multi-member profiles with data isolation and a summary dashboard**
- **Local-first encrypted storage with user-chosen backup (iCloud/Google Drive/WebDAV/local export)**
