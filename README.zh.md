# 安匣 SanCask

[English](README.md)

![安匣 Logo](resources/logo_256.png)

一款医疗病例收纳管理工具，拍照识别病历、检查报告与药品信息并结构化本机归档，提供指标趋势、用药分组与体检记录查看。

## 功能特性

- **拍照录入 + 本机 OCR，本地结构化字段抽取**
- **病历全生命周期管理：门诊/住院病历、跨医院疾病趋势分析、报告导出**
- **影像报告专科字段与影像附图裁切预览**
- **体检档案管理：指标年度趋势、结节/囊肿跟踪**
- **药品台账：拍照/手动录入、按病症分组、有效期提醒、按成员隔离**
- **多成员档案与数据隔离，首页看板聚合健康信息**
- **本地优先加密存储，自选备份（iCloud/Google Drive/WebDAV/本地导出）**
